
Superstore Sales Analysis
AI-Assisted End-to-End Data Analytics Project

 Project Overview
This is an AI-assisted end-to-end data analytics project focused on analysing Superstore sales performance, customer segments, product categories and shipping trends.

The project demonstrates the use of traditional data analytics tools combined with AI assistance to improve analytical workflows, problem-solving and business insights.

Tools & Technologies
- Microsoft Excel
- PostgreSQL
- Power BI
- Power Query
- DAX
- AI Tools (AI-assisted analysis and learning)

 Project Workflow

 1. Excel – Data Preparation & Analysis
- Data cleaning
- Data transformation
- Pivot table analysis
- KPI identification

 2. PostgreSQL – SQL Analysis
- Business-related SQL queries
- Filtering and aggregation
- CASE statements
- Subqueries
- Sales performance analysis

 3. Power BI – Dashboard Development
- Interactive dashboard development
- DAX measures
- Sales trend analysis
- Regional and category analysis
- Customer segment analysis
- Shipping performance analysis

 4. AI Assistance
AI tools were used to support:
- Analytical problem-solving
- SQL query learning and optimization
- Understanding DAX measures
- Dashboard planning and improvement
- Generating and refining business insights

 Dashboard Pages

 Page 1: Sales Overview
- Total sales and orders
- Yearly sales trends
- Regional performance
- Category performance

 Page 2: Detailed Sales Analysis
- Sub-category performance
- Customer segment analysis
- Shipping mode analysis

 Key Business Insights
- Total sales reached approximately 1M.
- Sales increased from approximately 200K in 2015 to 350K in 2018.
- West and East were the leading regions.
- Technology generated the highest category sales.
- Consumer was the largest customer segment.
- Standard Class contributed the highest sales.

 Conclusion
This project demonstrates an end-to-end data analytics workflow combining Excel, PostgreSQL, Power BI and AI assistance.

It highlights the practical application of data analysis tools and AI-assisted workflows to transform raw data into meaningful business insights.
